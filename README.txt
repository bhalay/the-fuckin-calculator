FUCKIN CALCULATOR — GitHub Pages edition

1. Create a public GitHub repository.
2. Upload index.html, icon.svg, manifest.webmanifest, and sw.js to the repository root.
3. Open Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open the GitHub Pages URL on your phone. On iPhone, use Safari > Share > Add to Home Screen.

Use the top-right gear icon for Step-by-Step and Unnecessary Steps. Both settings are saved locally in the browser. Voice has been completely removed.

Current algebra support: one-variable linear equations in x OR y, with parentheses, decimals and numeric fractions. Quadratics, simultaneous x/y equations and camera scanning are not supported. Standard and Scientific modes, history, and PWA offline caching are included.
